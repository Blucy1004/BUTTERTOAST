# 공통 AI 연결과 임시 UI

2026-11-07. ButterToast가 대화·페이지 공유·실행 승인·브라우저 작업·사용량 표시를 관리한다. 모델 서버에는 추론 요청만 보낸다. Supabase 계정 로그인 여부는 AI의 실행 권한이나 API 키를 제공하지 않는다. 최종 시각 디자인은 오너가 제공할 명세로 교체한다.

## 연결하기

브라우저 위쪽 `AI` 버튼으로 패널을 연다. `연결 설정`에서 API 형식을 선택하고 키를 입력한 뒤 `연결 확인`을 누른다. 연결 확인은 모델 목록 조회이며 모델 생성 요청은 메시지를 전송할 때 발생한다.

| 연결 | 기본 주소 | 인증 / 호출 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | Bearer 키, `/models`, `/chat/completions` |
| Claude | `https://api.anthropic.com/v1` | x-api-key, 버전 헤더, `/models`, `/messages` |
| OpenAI 호환 / 로컬 | 사용자가 입력한 base URL | `/models`, `/chat/completions`; 키 없는 로컬 연결 가능 |

로컬 서버 예: Ollama의 OpenAI 호환 API는 `http://127.0.0.1:11434/v1`, LM Studio는 `http://127.0.0.1:1234/v1`이다. 서버 실행과 모델 다운로드는 별도로 필요하다. 다른 HTTPS 호환 서버는 `/v1beta/openai`처럼 다른 base path도 사용할 수 있다. 이름이 같은 서비스라도 OpenAI 호환 API를 제공해야 이 형식으로 연결할 수 있다. 자체 형식의 API는 별도 어댑터가 필요하다.

외부 서버는 HTTPS만, HTTP는 `127.0.0.1`, `localhost`, `[::1]`만 허용한다. URL의 사용자 정보·쿼리·fragment·percent 인코딩은 거부한다. 키를 URL에 넣지 않는다. 기본 OpenAI/Claude 설정은 공식 주소에 고정되며 사용자 지정 주소는 호환 형식에서 입력한다. 주소를 바꿀 때 기존 키를 다른 서버로 자동 전달하지 않는다.

서버가 반환한 모델 ID 목록을 가져오며 첫 응답에서 최대 300개를 표시한다. 모델 API가 페이지를 나누면 현재 첫 페이지만 표시된다. 모델 ID를 직접 입력하고 `선택`할 수도 있다. 목록에 있다고 모든 모델이 텍스트 채팅을 지원하는 것은 아니다. 이미지·음성·임베딩 전용 모델은 이번 연결 범위 밖이다. 웹 구독과 API 사용 권한·요금은 별개다.

키는 신뢰된 설정 입력창에서 받은 직후 비우며 메인 프로세스에만 유지한다. `OS 암호화로 저장`을 명시적으로 선택한 경우 `KeyVault`와 OS 암호화로 저장한다. OS 암호화를 사용할 수 없으면 저장 옵션을 끄고 이번 실행 중에만 사용하는 방식을 직접 선택한다. 평문 파일 저장으로 대체하지 않는다. `저장된 연결`은 endpoint와 묶인 암호화 설정을 불러오고, `키 삭제`는 해당 제공사의 저장 키와 활성 연결을 해제한다. 저장 단위는 현재 OS 사용자/앱 프로필이며 Supabase 계정에 키를 업로드하거나 동기화하지 않는다.

## 대화와 페이지 공유

- 페이지 공유 없이 전송하면 사용자 메시지와 현재 대화만 보낸다. 다른 탭을 자동으로 읽지 않는다.
- `현재 탭 읽기` 또는 `AI 작업 읽기`를 누르면 HTTPS 페이지의 표시 텍스트와 일부 요소 설명을 미리 보여준다. 다음 메시지 한 번에만 포함된다.
- 입력란, textarea, select, contenteditable, data-private, 숨김 내용은 제외한다. 화면에 표시된 개인정보를 모두 판별할 수는 없으므로 미리보기를 확인한다. iframe·shadow DOM·전체 접근성 트리·화면 이미지는 이번 수집 범위 밖이다.
- 탭 변경, 탐색, 문서/DOM 버전 변경, 페이지 종료, 중단 시 공유와 실행 제안을 무효화한다. 모델 응답이 늦게 도착해도 새 탭으로 권한을 옮기지 않는다.
- 대화는 메모리에만 두며 최대 20개 메시지/45,000자 이내의 최근 대화를 유지한다. 연결을 바꾸거나 새 대화를 시작하면 이전 대화를 제거한다. 서버에 이미 전송한 데이터까지 회수하는 것은 아니다.

## AI 브라우저 작업

`별도 AI 작업 주소`에 HTTPS URL을 입력하면 사람 탭과 쿠키·저장소를 공유하지 않는 작업 창을 연다. 페이지를 읽고 요청을 전송하면 모델이 읽은 요소의 CLICK을 제안할 수 있다. 사람 탭 공유는 읽기 전용이며 모델 제안으로 클릭할 수 없다.

`클릭 검토`를 누르면 네이티브 승인 창에 실제 사이트와 요소 이름을 표시한다. 취소가 기본값이다. ToastGuard의 정확한 문서·버전·요소·동작에 연결된 일회성 승인을 통과해야 실행한다. 승인 중 요소 교체, DOM 변경, 중단, 작업 창 종료 및 재사용은 거부한다. 클릭이 전송·삭제·결제를 일으킬 수 있으므로 자동으로 무해하다고 분류하지 않는다.

이번 구현은 대화, 명시적 페이지 읽기, 사용자 승인을 받은 단일 CLICK까지다. 모델이 임의 JavaScript/셸 명령을 실행하거나 직접 grant/approve를 호출할 수 없다. FILL·SELECT·자동 NAVIGATE, 여러 단계의 자동 반복 실행, 사람 탭 제어권 인계, 여러 AI 동시 협업은 아직 없다. 작업 후에는 바뀐 페이지를 다시 공유해 다음 제안을 요청한다.

`중단`은 실행 권한과 첨부 내용을 해제하고 진행 중인 모델 요청·작업 페이지 로드를 중단한다. 이미 실행된 클릭이나 서버가 처리한 요청을 되돌리지는 않는다. `작업 종료`는 전용 WebContents와 메모리 저장소를 정리한다.

## 요청과 비용 범위

생성 요청은 사용자 전송당 한 번이며 자동 재시도하지 않는다. 최소 요청 간격은 1.5초, 대화당 최대 30회, 출력 상한은 2048 토큰, 요청 시간은 60초다. API 응답은 512 KiB, 페이지 텍스트는 12,000자와 최대 100개 요소, 입력 메시지는 12,000자로 제한한다. 페이지 읽기는 5초, 작업 창 탐색은 20초 제한을 둔다.

토큰 표시는 성공 응답에서 서버가 보고한 입력·출력·캐시 수치의 합이다. 오류·중단된 요청이나 서버가 수치를 제공하지 않는 경우 실제 청구 전체와 일치하지 않을 수 있다. 실제 잔액, 비용, 컨텍스트 잔여량을 임의로 만들어 표시하지 않는다. 가격표 기반 추정, 예산 설정, 영속 대화/작업 로그, SSE 스트리밍은 이번 범위 밖이다.

## 경계와 모듈

- `ai/protocol.ts`: 신뢰된 UI의 정확한 명령 스키마와 연결 주소 검증.
- `ai/adapter.ts`: 제공사별 요청/응답 변환. HTTP redirect, 쿠키 전송/보관, 원본 오류 노출을 금지한다. API 키가 응답에 그대로 포함되면 UI·후속 대화로 보내기 전에 제거한다.
- `ai/service.ts`: 메인 메모리의 연결·대화·컨텍스트·사용량·단일 제안, 취소 세대, 지연 응답 무효화.
- `ai/panel.ts`: 별도 샌드박스 UI WebContentsView와 엄격한 sender/frame/URL IPC 검사, 전용 모델 네트워크 세션, AI 작업 창 및 네이티브 승인.
- `ToastController` / `ToastGuard`: 기존 World 1001 DOM 매핑과 문서에 묶인 정책을 재사용한다. 모델 입력의 site/tab/version/approved 플래그를 신뢰하지 않고 메인이 제안 대상과 캡처 상태를 결합한다.
- `ai.html`, `ai.js`, `ai-settings.js`, `ai.css`, `tokens.css`: 임시 패널·설정·디자인 토큰. 탭·주소창·계정 화면과 독립적으로 교체할 수 있다. 과도한 카드/대시보드 화면은 추가하지 않았다.

## 검증 기록

`npm test`에 AI 단위 회귀 10개를 추가했다. 제공사 주소 고정과 로컬 HTTP 정책, 스키마/추가 권한 거부, OpenAI·Claude·호환 변환, 응답 크기와 오류/키 미노출, 저장 불가 시 거부, 키 삭제/연결 경쟁, 공유 없는 전송, 일회성 공유, 사람 탭 클릭 금지, 중단/탭 변경/지연 응답 및 일회성 제안을 검사한다.

`npm run test:ai`는 실제 production main, 네이티브 뷰, 설정·채팅 폼, IPC, 어댑터, ToastIR/Guard를 사용한다. OpenAI/Claude 응답은 로컬 프로토콜 fixture, 호환 API는 실제 loopback HTTP fixture다. 네이티브 승인 결과는 테스트에서만 승인/거절/승인 중 요소 교체를 제어한다. 로컬 AI E2E 12개 그룹이 통과했다. 최종 `npm run test:security`는 Node 61개 및 Electron 총 78개 그룹(기본 브라우저 16, ToastIR 19, 탭 생명주기 11, 확대 보안 12, 계정 8, AI 12)을 통과했다. 의존성 audit은 알려진 취약점 0건, 지원 패턴 비밀정보 검사도 통과했다. 이 결과를 실제 모델의 작업 정확도나 모든 프롬프트 인젝션에 대한 안전성 증명으로 취급하지 않는다.

실제 공식 `/models` endpoint는 OpenAI와 Claude 모두 키 없는 요청에 HTTP 401로 응답했다. 현재 유효한 AI API 키와 실제 로컬 모델이 제공되지 않았으므로 **유료 모델의 정상 응답, 실제 모델의 도구 제안 정확도, 실제 로컬 모델 추론은 미검증**이다. OS 키 암호화의 Windows 실행도 별도 확인이 필요하다. API 키를 채팅이나 저장소에 보내지 말고 앱의 연결 설정에서 입력한다.

이번 변경은 이전 Supabase 12자 갱신 토큰 호환 수정과 함께 작업공간에 유지한다. 환경 초안 변경, 환경 게시, GitHub push 및 Windows 배포는 수행하지 않았다.
