# ButterToast 구현 현황 — 2026-11-08

이번 작업 트리는 브라우저 기능·AI 실행·계정 복구·Windows 설치 빌드를 확장했다. **출시 검증이 끝난 완제품이라는 뜻은 아니다.** 최종 UI는 오너가 결정하며 메인 UI는 오너가 제공한 3패널 브리프를 적용했으며 계정·상세 설정은 교체 가능한 검증용 컴포넌트다.

0.2의 탭 검색·고정·음소거·주소 복제, 페이지 내 찾기·확대, 전역 AI 중지·충돌 복구, 다운로드 확인/출처 표시, 폰트 변경과 검증은 [확장 기록](UPGRADE-0.2.md)에 정리한다. 기존 탭 v1을 읽고 v2로 URL·고정·음소거를 저장한다. 입력·POST·AI 실행 권한은 복원하지 않는다. JASO Sans는 출처 확인 전이며 Pretendard만 포함했다.

## 검색·UI 결정

검색은 검색엔진의 정상 페이지를 연다. 자체 크롤러·색인과 검색 결과 재구성은 현재 범위에서 제외했다. Google 테마는 고정 CSS만 적용하며 검색 결과·광고를 삭제하거나 서버로 수집하지 않는다. 탭·주소창·관리 창·계정 창·AI 패널은 분리하고 디자인 토큰을 유지한다. 추가된 3패널·작업 넘기기·가상 커서·선택 공유의 범위는 [디자인 적용 기록](DESIGN-IMPLEMENTATION.md)에 정리한다.

## 검증

최종 실행 결과와 실제 검증 범위는 [0.2 변경 검증 기록](UPGRADE-0.2.md)에 정리한다. 외부 서비스의 실계정 검증과 로컬 응답 fixture 검증을 구분한다. 어떤 테스트도 취약점 부재를 보증하지 않는다.

## 출시 전 외부 설정·검증

1. 앱에서 실제 AI 키 또는 실행 중인 로컬 모델을 연결해 추론·동작 정확도를 확인한다. 키를 채팅이나 Git에 넣지 않는다.
2. Supabase 일반 사용자 가입/복구 메일용 SMTP와 도메인을 설정하고 실제 수신을 확인한다.
3. Windows 11에서 설치·탐색·OS 키 저장·메일 콜백·기본 브라우저·제거를 확인한다.
4. 배포자 코드 서명과 업데이트 호스팅/게시자 키를 준비한 후 출시한다. 개발용 사전 릴리스와 운영 출시는 구분한다.
5. 실제 모델과 복잡한 사이트에서 공격 회귀·성능/비용·성공률을 측정한다. PQ TLS 실제 협상 표시, 전체 AX/iframe/shadow DOM 범위는 추가 작업으로 남아 있다.
