## 우선순위와 검증 계획

1. ToastIR의 유계 DOM 수집, 민감정보/Shadow DOM 경계, 구조화 모델 표현과 변경분 재구성, 실행 결과·중지·오류를 먼저 보강한다.
2. 주소 자동완성·탭 정렬/자원 관리·탐색과 데이터 가져오기 같은 일상 브라우징 공백을 실제 UI와 연결한다.
3. 계정의 명시적 저장 선택, 공급자/공식 인증 준비, 무료 기능 권한·후원 표시 기반을 구현한다. 실제 승인/연결이 없는 기능은 비활성 상태와 이유를 표시한다.
4. 새 공격 fixture, 재현 가능한 자원/표현 벤치마크, 전체 회귀, Windows 패키지를 실행하고 이 기록을 갱신한다.

실제 비밀번호/결제/외부 계정 변경/사용자 데이터 삭제는 이번 개발 테스트에 사용하지 않는다. 일반적인 수정·로컬 검증은 사용자가 자율 진행을 승인했다. 배포·외부 서비스 등록은 기존 승인 범위와 새 지시서의 조건을 확인하고, 필요한 경우 완성된 산출물을 준비한 뒤 처리한다.
